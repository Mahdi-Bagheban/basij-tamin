## ✨ معرفی جامع
- پروژه ایستای سبک برای هدایت کاربر از انتخاب نیت تا ثبت پرداخت، با طراحی راست‌به‌چپ و تجربه کاربری روان.
- سازگاری کامل با موبایل/دسکتاپ، منوی چندسطحی شفاف، و فرم پرداخت فارسی با ارقام و نمایش تومان.
- استفاده از تصاویر WebP، فونت فارسی Vazirmatn، و افکت‌های بصری کم‌مصرف مطابق استانداردهای روز.

## 🚀 ویژگی‌های کلیدی
- منوی چندسطحی نیت‌ها با مدیریت فوکوس و جای‌گذاری هوشمند.
- فرم پرداخت با استان/شهر وابسته، اعتبارسنجی موبایل، و جمع کل زنده.
- شمارنده یادداشت اختیاری داخل کادر با انیمیشن نرم و محدودیت ۳۱۳ نویسه.
- افکت تشکر سبک با انیمیشن «کبوترها» هنگام ارسال.
- بهینه‌سازی‌های نسخه 6.7.5:
  - حذف بارگذاری تحلیلی در محیط محلی و فعال‌سازی فقط روی HTTPS برای رفع خطاهای Clarity.
  - تبدیل گسترده تصاویر به WebP و پاکسازی فایل‌های قدیمی.
  - افزودن بخش «توضیحات اختیاری»، شمارنده بلادرنگ و بهبود جایگذاری آن.
  - اصلاح اسکرول موبایل و فعال‌سازی اسکرول لمسی.

## 🛠️ راهنمای نصب دقیق
- پیش‌نیازها: یک وب‌سرور ساده یا باز کردن فایل‌ها با Live Server.
- مراحل:
  1) پوشه پروژه را در ریشه سایت مقصد قرار دهید.
  2) برای پیش‌نمایش محلی، فایل `index.html` را با افزونه Live Server باز کنید.
  3) در سایت مقصد، معمولاً فقط صفحات فرم را نیاز دارید: `payment-form.html` و دارایی‌های مرتبط.
- نکته امنیتی نسخه 6.7.5: بارگذاری Clarity فقط روی HTTPS/دامنه‌های غیرمحلی فعال است.

## 📘 مستندات استفاده
- مسیر کاربر:
  - صفحه کارت‌ها: انتخاب نیت و انتقال به فرم پرداخت.
  - فرم پرداخت: انتخاب استان → شهر، تعیین مبلغ (ثابت/دلخواه)، افزودن توضیحات اختیاری، و ارسال.
- پارامتر URL برای پیش‌انتخاب نیت:
  - `payment-form.html?cause=نذر_درمانی`
- سفارشی‌سازی محتوا:
  - ویرایش درخت نیت‌ها در `payment-scripts.js` داخل ثابت‌های داده‌ای.
  - تغییر استایل‌ها در `payment-styles.css` (رنگ‌ها، فاصله‌ها، متون، موقعیت شمارنده یادداشت).

## 💡 مثال‌های کد
- نمونه لینک با پیش‌انتخاب نیت:

```html
<a href="payment-form.html?cause=نذر_درمانی">پرداخت نذر درمانی</a>
```

- نمونه تغییر موقعیت شمارنده یادداشت با کلاس‌های آماده:

```html
<span id="notes-inline-count" class="notes-counter pos-tr">۰/۳۱۳</span>
```

```css
.notes-counter.pos-tr{ right:12px; top:8px }
```

- نمونه محدودسازی یادداشت به ۳۱۳ نویسه:

```html
<textarea id="donation-notes" maxlength="313"></textarea>
```

```js
const ta=document.getElementById('donation-notes');
ta.addEventListener('beforeinput',e=>{
  const sel=ta.selectionEnd-ta.selectionStart;
  if(/insert/i.test(e.inputType) && (ta.value.length-sel)>=313) e.preventDefault();
});
```
