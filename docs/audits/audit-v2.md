## ۳. بررسی امنیت وب و شبکه (Web Security &amp; Network)

### تأیید شده — نیاز به تغییر ندارد ✅
- بدون بک‌اند: هیچ سطح حمله‌ای برای SQLi/CSRF/IDOR/JWT وجود ندارد؛ فرم داده‌ای ارسال نمی‌کند.
- هندلرهای اینلاین حذف شده‌اند؛ سورس‌مپ‌ها از خروجی حذف شده‌اند؛ `noopener` رعایت شده است.
- `nginx.conf` هدرهای امنیتی (`X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`) + gzip + کش تفکیک‌شده دارد؛ خط CSP به‌صورت کامنت و مشروط به راستی‌آزمایی ارائه شده (تصمیم مستند، نه نقص).
- پکیج ونیل با نسخهٔ رسمی `2.7.12` در npm **بایت‌به‌بایت یکسان** تأیید شد (هیچ CVE شناخته‌شده‌ای برای این نسخه در پایگاه‌های عمومی ثبت نیست — بدون پکیج‌منیجر، `npm audit` موضوعیت ندارد).
