## ۲. بررسی کیفیت کد و استانداردهای وب (Code Quality &amp; Web Standards)

### تأیید شده — نیاز به تغییر ندارد ✅
- **نام‌گذاری** استاندارد (camelCase، نام‌های معنادار)، استفاده مداوم از `const`/`let` و optional chaining.
- **دسترس‌پذیری فراتر از میانگین**: skip-link، `aria-expanded/pressed/live/valuemin/max`، ناوبری کیبورد با roving tabindex در منوها، پشتیبانی `prefers-reduced-motion`، `aria-label` فارسی.

- توابع `utils.js` کوچک، خالص و قابل استفاده مجدد (KISS رعایت شده).

## ۳. بررسی امنیت وب و شبکه (Web Security &amp; Network)

### تأیید شده — نیاز به تغییر ندارد ✅
- **بدون بک‌اند، سطح حملهٔ کلاسیک عملاً صفر است**: SQL Injection، CSRF، IDOR و مدیریت Session/JWT موضوعیت ندارند (هیچ داده‌ای ذخیره/ارسال نمی‌شود؛ فرم فقط کلاینت‌ساید اعتبارسنجی و مودال تشکر نشان می‌دهد).
- `window.open(url, '_blank', 'noopener,noreferrer')` و `rel="noopener noreferrer"` روی لینک‌های تولیدی — محافظت در برابر reverse tabnabbing رعایت شده.
- اسکریپت Clarity فقط روی HTTPS و خارج از localhost فعال می‌شود (رفتار درست).
- اعتبارسنجی موبایل/نام/استان/شهر سمت کلاینت برای فرم بدون سرور کافی است.
